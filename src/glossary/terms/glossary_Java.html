--- layout: glossary title: What is Java? permalink: /glossary/java.html ---

An Object Oriented Programming Language originally developed by Sun Microsystems and now owned by Oracle. On the web it usually runs on the Server, so it works the same whichever browser a visitor uses. Java is also cross platform and is widely used for large business systems and Android apps.

Not to be confused with JavaScript, which is a language developed by Netscape that was designed to run in a Web Browser and is similar in name only.
