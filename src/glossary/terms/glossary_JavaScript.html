--- layout: glossary title: What is JavaScript? permalink: /glossary/javascript.html ---

A programming language originally developed by Netscape to run in a Web Browser. Unlike Java and PHP, which traditionally run on the server, JavaScript was designed to run in the user's web browser. Its uses are both numerous and powerful, from simple scripts that check the data entered into a form to whole web applications built with frameworks such as React and Vue.

JavaScript has advanced a lot since its humble beginnings and is now widely used across the internet. Using Node.js it can also run on the server, and it powers online computer games and recreations of desktop applications in the browser such as word processors, code editors and graphics programmes.
