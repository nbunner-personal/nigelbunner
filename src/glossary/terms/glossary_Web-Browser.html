--- layout: glossary title: What is a web browser? permalink: /glossary/web-browser.html ---

A web browser is a piece of software on your computer, phone or tablet that you use to view pages from the internet. If you're reading this, you're using a web browser right now.

There are various different browsers around. Google Chrome is the most widely used, followed by Safari, which comes with the Mac, iPhone and iPad. Microsoft's Edge replaced Internet Explorer, which has now been retired, and there are other browsers also worth checking out such as Firefox and Opera.
