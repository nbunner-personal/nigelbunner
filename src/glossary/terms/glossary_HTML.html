--- layout: glossary title: What does HTML mean? permalink: /glossary/hyper-text-markup-language.html ---

The markup language used to structure the content you see on a web page. It stands for Hyper Text Markup Language. If you choose View Source from your Web Browser's menu options you'll see the HTML code that makes up this page. All the HTML code used on the websites I design is handcoded to ensure it remains clean and Standards Compliant.
