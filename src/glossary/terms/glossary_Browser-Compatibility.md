<p>Most people use one <a href="/glossary/web-browser.html">web browser</a>, but there are several others, and each one has its own way of interpreting and displaying the code that makes up a website. Browser compatibility means making sure a site looks and works properly in all of them.</p>
<p>The <a href="https://www.w3.org/">World Wide Web Consortium (W3C)</a> and other standards groups publish guidelines for browser makers to follow. In the early 2000s browsers often ignored them, with older versions of Internet Explorer being the worst culprit, so web designers spent a lot of time writing fixes for each browser.</p>
<p>Things are much better now. Internet Explorer has been retired, and the main browsers (Chrome, Edge, Firefox and Safari) all update themselves automatically and follow the standards closely. There are still small differences, especially when using newer features, and sites also need to work on screens of every size, from phones to large monitors.</p>
<p>The sites I build are tested in Chrome, Firefox and Safari on desktop and mobile. To check whether a feature works in the browsers you need, have a look at <a href="https://caniuse.com/">Can I use</a>.</p>
